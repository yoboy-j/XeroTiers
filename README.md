# X4eroTiers

A lightweight Minecraft Paper plugin for managing competitive player tiers

## What It Does

Stores a tier for every player and shows it automatically on their nametag and tab list No configuration needed just set a tier and it works

## Tiers

Low Tiers: LT1 LT2 LT3 LT4 LT5

High Tiers: HT1 HT2 HT3 HT4 HT5

## Commands

`/tier <player>` - Check what tier a player has

`/tier set <player> <tier>` - Set a player tier

`/tier remove <player>` - Remove a player tier

`/tier reload` - Reload the config

Aliases: `/christiers` and `/t`

## Requirements

Paper 1.21.1 or higher

Java 21

PlaceholderAPI optional for placeholders

## Placeholders

`%x4erodev_tier%` - Returns the tier name like LT3 or HT5

`%x4erodev_tier_colored%` - Returns the tier with color

## Config

Open `plugins/x4erodevtiers/config.yml` to change colors

## API

Other plugins can use the API to get set or remove tiers
